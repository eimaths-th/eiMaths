Run in the deployed Laravel project:

No database migration or frontend build is required.

Expected events:
- /students-login: PageView
- Opening the Free Trial panel: OpenFreeTrialForm (custom, once per page load)
- /free-quiz/register: PageView and OpenFreeTrialForm
- Successful new trial registration: CompleteRegistration on the redirected home page
- Successful existing trial or student login: ELearningLogin (custom) on the redirected home page
- Redirected success pages also send PageView when loading the Pixel.
- Auto-login during registration does not also count as ELearningLogin.
- Failed/duplicate registration, bad password and expired trial do not send success events.
- Refreshing a success page consumes no new success event; its session marker was already removed.
- Ordinary quiz/home navigation without a fresh success marker does not load this Pixel.
- Localhost, test-web and other hosts do not load this integration.

No form fields, names, emails, phone numbers, passwords, student identifiers, grades,
schools, quiz answers or results are passed as event parameters. Automatic configuration
is disabled, and advanced matching is not added. Standard Meta Pixel browser/page
metadata and cookies still apply. Do not place personal data in page URLs.

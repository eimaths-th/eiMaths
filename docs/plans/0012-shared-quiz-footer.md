# Shared Quiz Footer Implementation Plan

> **REQUIRED EXECUTION SKILL:** After plan approval, use `executing-plans` with the previously selected native execution method and final review. Do not create a worktree.

- **Goal:** Make the shared learning-site footer orderly and consistent across Home, Quiz, Result, Test Preview, and Leaderboard consumers of `layouts.quiz_layout`.
- **Architecture:** Rewrite the existing `home.footer` presentation and give it one scoped stylesheet. Remove the competing Result and Preview footer overrides. Preserve the shared layout inclusion and all contact destinations.
- **Tech Stack:** Laravel Blade, scoped CSS, existing translations and logo, existing PHPUnit view checks, native browser verification with actual Vite assets.

## Global Constraints and Design Decisions

- Work on the existing `demo` checkout at HEAD `4fb6262306765c24e7e079ed45573f9e06d657ac`, preserving all pending unrelated work. No commit, deployment, database changes, dependencies, or worktree.

Keep `footer_learning_center`, `footer_mission`, and `footer_mission_detail` once in the brand column; remove the standalone repeated mission column. Keep existing bilingual branch names as displayed today.

Use existing Font Awesome icons as decorative, `aria-hidden` icons beside meaningful text links; no icon-only contact controls. Give links at least 44px height, wrapping, visible underline on hover, and a 2px orange focus outline with offset. No motion, gradients, blur, shadows, or inline mouse handlers.

- External links retain their existing new-tab behavior and receive `rel="noopener noreferrer"`. Telephone links retain their protocol and destination. Do not call phone numbers or open external contacts during testing.
